The Problem

Most software has no idea how you actually are.

Interfaces are built to register what you click, type, or buy — rarely how focused, fatigued, stressed, or receptive you are in that moment. Every interaction is treated as context-free, as if the same person in a completely different state should be met with an identical experience.

Computing should not only understand what you do.
It should increasingly understand how you are. — Innermind Technologies
