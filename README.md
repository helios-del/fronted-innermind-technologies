# Innermind Technologies website

Static website prepared for deployment on Vercel.

## Deploy
Upload these files to the GitHub repository connected to Vercel. No build command is required for this static version.

## Before launch
- Replace the contact email if `contact@innermindtech.com` is not the intended address.
- Review all company/technology claims.
- Add the complete 15-dimension model only after the dimensions and wording are final.
- Connect `innermindtech.com` in Vercel after the deployment is working.
